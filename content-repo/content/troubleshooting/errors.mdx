## 通用排障步骤

<Steps>
  <div>
    **检查 API Key**

    确认 Key 未过期、未禁用，且在请求头里以 `Bearer` 前缀传入。
  </div>
  <div>
    **检查请求参数**

    对照 [Chat Completions API](/docs/api/chat-completions) 的参数表，确认必填字段齐全、类型正确。
  </div>
  <div>
    **看响应里的 error.message**

    响应 JSON 的 `error.message` 字段通常有具体原因，照着改。
  </div>
</Steps>

## 429 限流处理

<Callout variant="danger" title="429 必须重试，不要直接报错给用户">
  收到 429 时，用指数退避重试（1s → 2s → 4s → 8s），最多重试 3-5 次。如果持续 429，说明触发了持续限流，需要降频或联系运营提额。
</Callout>

重试示例（Python 指数退避）：

<CodeTabs tabs={[
  { label: 'Python', code: 'import time\nimport requests\n\ndef call_with_retry(url, headers, payload, max_retries=5):\n    for i in range(max_retries):\n        resp = requests.post(url, headers=headers, json=payload)\n        if resp.status_code == 429:\n            wait = 2 ** i  # 1, 2, 4, 8, 16 秒\n            print(f"限流，{wait}秒后重试 ({i+1}/{max_retries})")\n            time.sleep(wait)\n            continue\n        return resp\n    raise Exception("重试次数耗尽")' }
]} />

## 错误响应格式

所有错误响应都是统一结构：

```json
{
  "error": {
    "type": "invalid_request_error",
    "message": "model field is required"
  }
}
```
