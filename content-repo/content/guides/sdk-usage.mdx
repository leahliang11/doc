## 接口概述

JoyMaaS 兼容 OpenAI API 格式，可直接用 OpenAI 各语言 SDK，只需替换 `base_url` 和 `api_key`。也提供官方 SDK `@joymaas/sdk`。

## 安装 SDK

<CodeTabs tabs={[
  { label: 'Python OpenAI SDK', code: 'pip install openai' },
  { label: 'Node OpenAI SDK', code: 'npm install openai' },
  { label: '官方 SDK (Node)', code: 'npm install @joymaas/sdk' }
]} />

## 基本调用

### 用 OpenAI SDK（推荐）

<CodeTabs tabs={[
  { label: 'Python', code: 'from openai import OpenAI\n\nclient = OpenAI(\n    api_key=os.environ["JOYMAAS_API_KEY"],\n    base_url="https://api.joymaas.com/v1",\n)\n\nresp = client.chat.completions.create(\n    model="DeepSeek-V4-Flash",\n    messages=[{"role": "user", "content": "你好"}],\n)\nprint(resp.choices[0].message.content)' },
  { label: 'Node', code: 'import OpenAI from "openai";\n\nconst client = new OpenAI({\n  apiKey: process.env.JOYMAAS_API_KEY,\n  baseURL: "https://api.joymaas.com/v1",\n});\n\nconst resp = await client.chat.completions.create({\n  model: "DeepSeek-V4-Flash",\n  messages: [{ role: "user", content: "你好" }],\n});\nconsole.log(resp.choices[0].message.content);' }
]} />

<Callout variant="info" title="为什么用 OpenAI SDK">
JoyMaaS 接口兼容 OpenAI 格式，直接复用 OpenAI 成熟的 SDK 生态（类型完整、流式、错误处理、重试都内置），无需额外适配。
</Callout>

## 错误处理

SDK 调用可能抛异常，建议 try-catch + 按 429/500 分别处理：

<CodeTabs tabs={[
  { label: 'Python', code: 'from openai import OpenAI, APIError, RateLimitError\n\ntry:\n    resp = client.chat.completions.create(...)\nexcept RateLimitError:\n    time.sleep(2)\n    # 重试\nexcept APIError as e:\n    print(f"API 错误: {e}")' },
  { label: 'Node', code: 'try {\n  const resp = await client.chat.completions.create({...});\n} catch (e) {\n  if (e.status === 429) {\n    await new Promise(r => setTimeout(r, 2000));\n    // 重试\n  } else {\n    console.error("API 错误:", e);\n  }\n}' }
]} />
