## 接口概述

JoyMaaS 对每个 API Key 施加 RPM（每分钟请求数）和 TPM（每分钟 token 数）双重限流，防止单 Key 占用过多资源。

## 默认限额

| 模型类型 | 默认 RPM | 默认 TPM | 说明 |
|---|---|---|---|
| Chat（对话） | 1000 | 2,000,000 | 单 Key 默认值 |
| Embedding（向量） | 2000 | 4,000,000 | 向量接口限额较高 |
| Moderation（审核） | 2000 | 4,000,000 | 轻量接口 |

<Callout variant="info" title="限额可提升">
默认限额针对普通账号。企业客户可在控制台「配额管理」申请提升，或联系商务。
</Callout>

## 429 错误

超过限额时接口返回 HTTP 429，响应体含具体限流维度：

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Rate limit exceeded for RPM",
    "type": "rate_limit_error"
  }
}
```

## 响应头

每次调用响应头会返回当前限额状态，便于客户端自适应调节：

## 重试实践

收到 429 时应按 `Retry-After` 头等待后重试，或用指数退避：

## 客户端优化建议

- **批量请求合并**：Embedding 支持单次传数组，把多条文本合并一次调用，降低 RPM
- **流式优先**：长文本生成用 `stream: true`，单请求占 RPM 少
- **缓存结果**：相同输入的 Embedding 结果建议缓存，避免重复调用
- **错峰调用**：高峰期（工作日 10-12/14-16）限额更紧张，非实时任务可错峰

<InternalOnly>
内部限流策略：单 Key 默认 1000 RPM / 2000000 TPM，超出返回 429。SLA：P99 < 2s，可用性 99.9%。容量水位看内部监控大盘 `joymaas-api-capacity`。限流维度可按客户等级动态调整，配置在 `rate_limit_config` 表。
</InternalOnly>
