## 接口概述

```http
POST /v1/embeddings
```
将输入文本转为向量，用于相似度检索、聚类、分类等场景。兼容 OpenAI Embeddings API 格式。

<Callout variant="info" title="兼容 OpenAI 格式">

本接口兼容 OpenAI Embeddings API，已有 OpenAI 客户端只需替换 base_url 和 api_key。

</Callout>

## 请求参数

<Params params={[
  { name: 'model', type: 'string', required: true, description: '模型 ID，如 embedding-3。完整列表见 /v1/models' },
  { name: 'input', type: 'string', required: true, description: '要向量化的文本，单个字符串或字符串数组' },
  { name: 'encoding_format', type: 'string', required: false, default: 'float', description: '返回向量的格式，float 或 base64' },
  { name: 'dimensions', type: 'integer', required: false, description: '输出向量的维度，部分模型支持降维（如 embedding-3 支持 512/1024/2048）' },
  { name: 'user', type: 'string', required: false, description: '终端用户标识，用于用量统计与滥用追踪' }
]} />
