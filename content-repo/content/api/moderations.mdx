## 接口概述

```
POST /v1/moderations
```
对输入文本进行内容审核，识别是否包含有害、暴力、色情等违规内容。返回各分类的命中标志与置信度分数。

<Callout variant="info" title="分类说明">

返回的 categories 与 category_scores 覆盖 hate/threatening/self-harm/sexual/violence 等标准分类，category_scores 为 0-1 的置信度。

</Callout>

<Params params={[
