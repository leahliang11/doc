## 接口概述

```
POST /v1/chat/completions
```

创建一个对话补全。给定一组消息列表，模型返回一个补全响应。

<Callout variant="info" title="兼容 OpenAI 格式">
  本接口兼容 OpenAI Chat Completions API，已有的 OpenAI 客户端只需替换 `base_url` 和 `api_key` 即可。
</Callout>

## 流式响应

设 `stream: true` 时，响应以 SSE（Server-Sent Events）返回，每行一个 `data:` 块：

```
data: {"id":"chatcmpl-abc","choices":[{"delta":{"content":"你好"},"index":0}]}

data: {"id":"chatcmpl-abc","choices":[{"delta":{"content":"！"},"index":0}]}

data: [DONE]
```

<Callout variant="warning" title="流式处理注意">
  流式模式下，客户端需按行解析 `data:` 前缀，遇到 `[DONE]` 结束。不要把整个响应当作一个 JSON 解析。每个 chunk 的 `choices[0].delta.content` 是增量内容。
</Callout>
