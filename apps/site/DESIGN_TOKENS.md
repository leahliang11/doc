# JoyMaaS 开发者文档视觉规范

> 版本：B 主风格 + C API 模板。整体采用明亮、克制的开发者文档风格；信息架构以快速定位为先，API 页面使用参数与代码并列的工作台布局。

## 1. 核心原则

1. **先解决问题，再展示品牌**：导航、搜索、参数与示例是页面主角，品牌色只用于识别和操作反馈。
2. **明亮但不松散**：白色内容面板置于冷灰画布上，用紧凑的 8px 节奏、边框和必要留白建立层级，禁止用大块空白制造“高级感”。
3. **API 可直接工作**：接口地址可复制，请求参数在左、可运行示例在右；窄屏自动回到单列。
4. **组件语义一致**：提示、步骤、参数、代码、内部信息与下一步均有稳定结构，不由每篇文档自由发挥。
5. **与 JoyMaaS 官网同源**：品牌与通用交互统一使用纯色紫 `#7257E8`，浅底使用 `#F1EFFC`；不使用渐变。
6. **颜色必须有职责**：紫色负责品牌与通用交互；橙、红、绿只表达提醒、错误、成功等明确状态，不引入蓝色装饰体系。

## 3. 字体与层级

- 主字体：Inter / 系统无衬线，正文使用 400，标签和小标题使用 500/600。
- 代码：Geist Mono / 系统等宽。
- 页面标题：28–34px / 600 / 紧凑字距。
- 章节标题：20px / 600；小节标题：16px / 600。
- 正文：14px / 1.68；组件说明：12–13px / 1.6。
- 元数据和辅助标签：11–12px。

## 4. 布局

### 全局

- 顶部导航高 64px，最大内容宽度 1500px。
- 桌面端左侧导航宽 220px，页面与导航边界使用 1px 冷灰线。
- 普通文档正文按可用空间伸展，正文有效宽度约 750–890px，右侧目录 168px。
- 页面栅格间距 24px；正文面板桌面内边距 30–34px，圆角 10px，常态仅保留非常轻的 1px 阴影。
- 章节之间 32px，段落之间 12px，常规组件上下间距 12–16px；不允许连续叠加多层大间距。

### API 工作台

- 桌面端左侧为接口说明和参数，右侧为浅色代码示例，约 `1 : 0.92`；代码区使用浅灰底与细边框，避免大面积深色造成视觉压迫。
- 接口方法、路径和复制入口合并为一个 Endpoint Bar。
- 请求示例代码固定在右栏首屏；低于 1200px 时回到正文流中。
- 参数表桌面使用表格，移动端切换为纵向参数卡。

## 5. 圆角、边框与阴影

- 小控件：5–7px；内容组件：7–8px；大面板：10px。
- 常态优先使用边框建立层次，禁止大面积重阴影。
- 可点击卡片 hover 可上移 1–4px，并使用低透明度品牌紫阴影。
- Logo、按钮、选中线、页面背景均使用纯色或透明度层次，禁止使用线性、径向或多色渐变。
- focus 使用 `--ring`，必须保留键盘可见反馈。

## 6. 组件规范

### Callout

- 不使用语义色侧边线；用低饱和度浅色背景、同色弱边框和 14px 小图标表达类型。
- 信息用品牌紫浅底、注意用淡橙、风险用淡红、成功用淡绿；不使用蓝色、黄色或琥珀色装饰。
- 上下内边距 8px，标题与正文优先同行，标题 12.5px/600，正文 12.5px/1.6，整体圆角 7px。

### Steps

- 序号使用 24px 品牌紫浅底方圆标记，采用 `01/02` 等等宽编号；步骤间用 1px 中性线连接。
- 步骤间距 16px，步骤内容与编号独立排版，避免把流程做成松散的大卡片。

### Params

- 表头使用冷灰底；参数名使用主色等宽字体，必填状态与参数名合并展示。
- 类型和默认值直接使用紧凑等宽文本，不套大面积徽标；桌面表格固定为“参数 / 类型 / 默认值 / 说明”四列。

### CodeTabs

- 整体使用 `#0F172A` 深色工作区，顶部标签栏略亮一档。
- 当前标签使用品牌紫下划线，不使用大面积按钮填色；标签栏高 36px，代码区内边距 14–16px。
- 复制操作固定在右上角，不覆盖代码；代码区最大高度 520px。

### InternalOnly

- 使用中性灰浅底、虚线边框和小型等宽 `INTERNAL` 标签，不使用彩色侧边线。
- 收起高度控制在 36px 左右，展开态保持紧凑。

### NextSteps

- 多个入口合并为一个轻边框列表，单项高度约 56px，不再使用互相分离的大卡片。
- hover 只使用浅品牌底与箭头位移，不上浮，避免正文尾部视觉噪声。

## 7. 响应式与可访问性

- 1200px 以下：API 工作台改为单列；代码示例回到对应章节。
- 1280px 以下：隐藏右侧目录；正文居中。
- 768px 以下：正文边距缩至 14–20px，标题与复制按钮改为纵向布局。
- 所有图标按钮必须有 `aria-label`；导航激活项使用 `aria-current`。
- 支持深色模式与 `prefers-reduced-motion`。

## 8. 验收清单

- [ ] 普通文档与 API 文档的视觉结构明显不同，但使用同一套 Token。
- [ ] API 首屏同时可看到接口地址、参数入口和调用示例。
- [ ] 搜索可通过 `⌘/Ctrl + K` 打开，并能跳转到文档。
- [ ] 左侧导航能准确标出当前页面和 API 方法。
- [ ] 六类 MDX 组件在桌面与移动端均无溢出或遮挡。
- [ ] 浅色、深色模式均满足正文与交互控件的对比度要求。
- [ ] 全站不存在装饰性蓝色或渐变；紫色只按 Token 使用，语义色只承担状态表达。
